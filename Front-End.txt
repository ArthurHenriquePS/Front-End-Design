Aula 6 

Label: Descreve o campo ao usuário e melhora a acessibilidade
Input: Campo onde o usuário digita ou seleciona os dados
fr + id: Conecta o label ao input correspondente

TYPES
text = Campo de texto livre
email = Valida formato de e-mail automaticamente
password = censura o que está escrito
number = Aceita apenas valores númericos
radio = Seleciona uma opção entre várias
checkbox = Marca uma ou mais 
date = Exibe o seletor de datas
file = permite envio de arquivos

TYPE TEXT 
maxlegth = Limita o número máximo de caracteres
minlegth = Exige um número mínimo de caracteres
required = Torna o campo obrigatório
value = Define um valor padrão já preenchido no campo
placeholder = Texto exibido na label para o usuário

TYPE E-MAIL
Valida automaticamente se o valor digitado possui o formato correto de e-mail

<select> = Cria uma lista suspensa (dropdown) com opções predefinidas. Ideal quando há muitas opções para exibir como radio buttons
<option> = Usada para cada opção das selects

<textarea> = Cria um campo de texto multilinha, perfeito para mensagens longas, comentários e descrição que não cabem em um <input type="text">
rows = tamanho de linhas
cols = tamanho de colunas

Aula 7

CSS = Cascading Style Sheets

tag = todos os elementos iguais
.classe = grupos de elementos
#id = um elemento único

TAGS
color = Cor do texto
background-color = Cor de fundo
font-family = Tipo
font-size = Tamanho do texto
text-align = Alinhamento de texto

ESPAÇAMENTO
padding = Espaço de dentro da caixa - entre o conteúdo e a borda
margin = Espaço de fora da caixa - entre o elemento e os vizinhos

BORDAS
border: "expessura" "estilo(sólida)" "cor";
border-radius = Arredondar a vértice da forma (50% = círculo perfeito)

INTERAÇÃO COM :HOVER
:hover = pseudo-classe que aplica estilos quando o usuário passa o mouse sobre um elemento
